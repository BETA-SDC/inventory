# 标签打印

管理员为已登记的资产、批次和位置生成标签。PDF 默认 A4，每页十个标签，单个 90 × 45 mm，适用于普通纸裁切或尺寸相符的标签纸。

中文字体随仓库提供，PDF 内嵌实际使用的字形，不依赖阅读器另装中文字体包。字体来源与许可证见 [字体说明](../assets/fonts/README.md)。

```bash
python3 scripts/inventory.py check
python3 scripts/inventory.py build
.venv/bin/python scripts/labels.py --ids AST-000001 BAT-000001 LOC-000001 --output output/pdf/labels.pdf
```

使用实际编号；不存在的编号会拒绝生成。输出默认在忽略的 `output/pdf/`，打印产物不必提交到 Git。支持选择部分编号补打，重复编号只打印一次。

资产标签不显示可变的存放位置、负责人或联系方式。批次标签显示基本单位，食品显示到期日期。二维码链接到 `views/objects/` 或 `views/locations/` 的稳定公开档案。档案包含当前库存、未结借用和预填编号的申请入口。

打印前先把最新档案与查询页面提交并推送，否则二维码可能打开尚未存在的页面。打印选择原尺寸／100%，不要“适应页面”。先打一页普通纸测量尺寸，再打印标签纸。当前排版不匹配特定品牌的预切标签纸，使用前检查纸张间距。

打印后核对编号与实物；贴在容易看到且不影响使用的位置。食品标签不能遮挡原包装日期和保存要求。无法逐件贴标时使用周转箱或货位标签，保持不同批次可区分。
