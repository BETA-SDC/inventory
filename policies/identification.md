# 实物编号与存放位置

## 编号

`ITM` 表示物品定义，`AST` 表示逐件资产，`BAT` 表示库存批次，`LOC` 表示位置，`EVT` 表示操作，`STK` 表示盘点。六位流水从 `000001` 开始，由管理员工具分配。

编号不包含日期、位置、负责人或状态。旧编号不重复使用。报废、耗尽或停用后保留档案及引用。

## 位置

位置采用层级：园区 / 楼栋 / 房间 / 柜子或货架 / 层或格口。每级位置可有独立编号，填写 `parent`、`name`、`description` 和 `storage`。只有 `storage: true` 的位置用于出入库。

完整地址由工具展开上级链，不手工复制到每份资产档案。定位说明须足以找到实物，例如“进门右侧白柜，第 2 层左格”。公共区域之外的访问说明按私有信息规范保存。

位置搬迁后保留原编号及说明，确实新建货位时建立新编号，再登记调拨。资产外借以 GitHub 用户名记录去向，不把私人住址作为公开货位。

## 标签

- 资产：编号、名称、二维码；必要时补充型号。
- 批次：编号、名称、基本单位、到期日期、二维码。
- 货位：编号、位置名称、二维码。
- 可读编号必须清楚；二维码损坏时仍能人工查找。
- 标签不印手机号、访问码或借用人资料。
- 食品标签不能遮挡原包装的日期、成分和保存说明。
- 无法逐件贴标的物资使用周转箱或货位标签，批次混放时必须保留批次区分。

标签生成与打印排版在第三阶段实现。目前编号可人工写在临时标签上，必须与档案一致。
