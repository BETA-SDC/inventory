# 私有信息

本仓库沿用组织的[公开侧私有信息引用规范](https://github.com/BETA-SDC/community/blob/main/docs/procedures/privacy/private-information-reference.zh.md)和[联系方式维护指南](https://github.com/BETA-SDC/community-private-information/blob/main/guides/contact-maintenance.zh.md)。

## 提交

手机号等联系方式保存到 `community-private-information` 的已有联系人条目。优先更新已有条目，不重新建一份物资管理联系人名单。

公开 Issue 填写 GitHub 用户名及普通私有联系人链接，例如指向 `text/contacts/` 的稳定标题。没有私有仓库访问权限时联系管理员办理；管理员审核时核实联系方式，申请中不复制内容。

公开链接文字使用“私有联系人记录”等用途说明，不含敏感信息。公开业务说明不依赖私有链接才能理解。

## 附件

上传实物照片前检查画面中的人脸、手机号、快递面单、访问码和非公开票据。敏感附件按组织规范放在私有仓库，仅在必要位置引用。

## 自动化

公开工具只校验联系人引用的格式，不抓取私有内容。不得把私有内容输出到 Actions 日志、标签、Markdown 台账或 Issue 评论中。折叠块和 HTML 注释仍是公开内容，不能用作隐藏提交。
